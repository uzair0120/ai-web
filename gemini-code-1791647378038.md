# AI-Powered Secure Document Search Portal

Ye project ek client-side RAG aur AI assistant web application hai jo GitHub Pages par bina kisi server (XAMPP/PHP) ke direct live chal sakti hai.

## Features:
- File Upload & Browser-based RAG Processing
- OpenAI GPT-4o-mini Integration
- Multilingual Voice Recognition & Text-to-Speech
- 100% compatible with GitHub Pages
